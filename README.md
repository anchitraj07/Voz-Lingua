# VOZ LINGUA

A polished React + Vite landing website for VOZ LINGUA, a French learning academy.

## Run locally

Requirements:
- Node.js 20+ recommended

```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

## Build

```bash
npm run build
```

## What is included

- Responsive landing page
- VOZ LINGUA brand header
- Hero section
- Course cards A1–B2
- VOZ Method section
- About section
- FAQ accordion
- Free demo lead form
- Responsive mobile navigation
- No backend dependency

## Before production

Replace the demo form handler with:
- WhatsApp Business link, or
- Form backend / email service, or
- Your own Spring Boot/Node backend.

Recommended next integrations:
1. WhatsApp lead capture
2. Google Calendar / booking
3. Student registration
4. Payment gateway
5. CMS/LMS
6. Analytics
7. SEO metadata and domain
